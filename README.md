# 🛡️ Ubuntu VPS Security Audit

**Простой аудит безопасности Ubuntu VPS без установки дополнительных программ.**

Скрипт проверяет основные системные параметры, пользователей, SSH-доступ, сетевые соединения, службы, планировщики задач, Docker и целостность установленных пакетов.

> Скрипт предназначен для предварительной проверки сервера. Он не является полноценным антивирусом или гарантией обнаружения взлома.

## ✨ Возможности

Скрипт выполняет 18 групп проверок:

| № | Проверка | Что анализируется |
|---|---|---|
| 1 | Пользователи и права | UID, root-аккаунты, группа sudo |
| 2 | SSH-настройки | Порт, вход root, парольная и ключевая авторизация |
| 3 | SSH-ключи | Файлы authorized_keys и отпечатки ключей |
| 4 | Успешные SSH-входы | История подключений и подтверждение IP пользователем |
| 5 | Неудачные SSH-входы | Ошибки авторизации и попытки подбора паролей |
| 6 | Fail2ban | Состояние службы и SSH jail |
| 7 | Сетевые порты | Прослушиваемые порты и активные соединения |
| 8 | Процессы | Список процессов с сортировкой по CPU |
| 9 | Systemd | Неисправные и включённые службы |
| 10 | Systemd Timers | Запланированные системные задачи |
| 11 | Cron | Системные и root-задачи |
| 12 | Изменённые системные файлы | Недавно изменённые файлы в важных каталогах |
| 13 | Docker | Контейнеры и образы |
| 14 | Целостность пакетов | Проверка `dpkg -V` |
| 15 | Модули ядра | Загруженные модули |
| 16 | Системные ошибки | Ошибки журнала systemd за последние 7 дней |
| 17 | Временные каталоги | Исполняемые файлы в `/tmp`, `/var/tmp`, `/dev/shm` |
| 18 | Итог | Предупреждения и ограничения проверки |

## 🚀 Быстрый запуск

**Установка не требуется.** На Ubuntu VPS выполни команду от имени `root`:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/harrypotniy55-a11y/ubuntu-vps-security-audit/main/server-audit.sh)
```

Если ты вошёл под обычным пользователем, сначала переключись на root:

```bash
sudo -i
```

Затем выполни команду запуска.

## 📋 Результаты проверки

Скрипт разделяет результаты на три категории:

- `[ПРЕДУПРЕЖДЕНИЕ]` — обнаружено событие или объект, требующий проверки.
- `[ОГРАНИЧЕНИЕ ПРОВЕРКИ]` — данные недоступны или проверка выполнена не полностью.
- `[ИНФО]` — информационное сообщение, само по себе не указывающее на проблему.

В конце отображается один из результатов:

- **ОБНАРУЖЕНЫ ПРЕДУПРЕЖДЕНИЯ** — нужно изучить отмеченные события.
- **ПРОВЕРКА ВЫПОЛНЕНА НЕ ПОЛНОСТЬЮ** — есть ограничения сбора данных.
- **ПРЕДУПРЕЖДЕНИЙ НЕ ОБНАРУЖЕНО** — автоматические проверки не отметили подозрительных событий.

Неизвестный IP не считается доказательством взлома. Скрипт спрашивает пользователя, знаком ли ему адрес успешного SSH-входа.

## 📄 Отчёт

Результат сохраняется в:

```text
/root/audit-report.txt
```

Отчёт можно посмотреть командой:

```bash
less /root/audit-report.txt
```

## 🔒 Безопасность

Скрипт не изменяет:

- конфигурацию SSH;
- правила Firewall;
- настройки Fail2ban;
- службы systemd;
- Docker-контейнеры;
- сетевые настройки;
- системные пакеты.

Скрипт создаёт локальный отчёт и временный файл, который удаляется после завершения работы.

## ⚠️ Ограничения

Это предварительный аудит, а не полноценное расследование инцидента.

Скрипт не гарантирует обнаружение:

- руткитов и скрытого вредоносного ПО;
- всех вариантов компрометации сервера;
- вредоносного кода внутри легитимных процессов;
- изменений, не отражённых в проверяемых журналах;
- проблем, требующих внешнего сетевого сканирования.

Изменённые файлы пакетов, неизвестные IP, исполняемые файлы во временных каталогах и неисправные службы требуют ручной оценки. Они не обязательно означают взлом.

## 🖥️ Поддерживаемые системы

- Ubuntu 22.04 LTS
- Ubuntu 24.04 LTS
- Bash
- Права root
- `curl` для запуска непосредственно с GitHub

Большинство используемых команд входит в стандартную систему Ubuntu. Отсутствие отдельных инструментов будет отражено в результатах проверки.

## 📦 Локальный запуск

Если файл уже находится на сервере:

```bash
chmod +x server-audit.sh
sudo ./server-audit.sh
```
